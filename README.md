CodeFusion 2026 – Web Development Mini Hackathon

12 Teams • 12 Sections • 1 Website

CodeFusion 2026 is a 2-hour in-class mini hackathon designed to give students practical experience with HTML and CSS through team-based development and GitHub collaboration.

The activity brings together 12 teams to build one static website. Each team is responsible for one section of the website, and all 12 sections are combined into a single final web experience.

🎨 CSS Approach

The project uses external CSS. Each team has its own index.html and style.css.

In the combined website, Team-specific CSS is scoped using the section ID so that one team's styling does not unintentionally affect another team.

Example:

#team1 {
    ...
}

#team1 .box {
    ...
}

#team1 h1 {
    ...
}

Team 2 follows the same pattern with #team2, and so on through #team12.

📋 Team Rules

Work only on the assigned Team folder.

Use index.html for HTML.

Use style.css for external CSS.

Keep the code simple and readable.

Do not unnecessarily change another team's section.

Use HTML and CSS concepts covered in class.

Test the webpage before submission.

Check links, images, forms, tables, lists and styling.

Use meaningful Git commit messages.

Submit completed work through GitHub.

⏱️ 2-Hour Hackathon Flow

Phase 1 – Understand

Students receive the team number, assigned section, required concepts and GitHub instructions.

Phase 2 – Develop

Each team develops its assigned index.html and style.css.

Phase 3 – Test

Teams check HTML structure, CSS application, navigation, images, forms, tables, lists and required CSS concepts.

Phase 4 – Submit

Teams commit, push and create a Pull Request.

Phase 5 – Integrate

The submitted sections are integrated into the final CodeFusion website.
