CodeFusion 2026 – Web Development Mini Hackathon

12 Teams • 12 Sections • 1 Website

CodeFusion 2026 is a 2-hour in-class mini hackathon designed to give students practical experience with HTML and CSS through team-based development and GitHub collaboration.

The activity brings together 12 teams to build one static website. Each team is responsible for one section of the website, and all 12 sections are combined into a single final web experience.

🌐 Live Website

Live Demo: https://codefusionwebtec.netlify.app/

📌 Project Repository

GitHub Repository: https://github.com/PranuthHM/CodeFusion_3CSE07_WebDevelopment_AY2026

🎯 Objectives

Practise HTML Module 1 concepts.

Practise CSS Module 2 concepts.

Build a static webpage using HTML and external CSS.

Understand webpage structure and layout.

Apply CSS selectors and basic styling.

Work as a team on a common website.

Use GitHub for collaborative development.

Understand fork, clone, edit, commit, push and Pull Request.

Integrate individual team sections into one final website.
